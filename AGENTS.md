# Agent Rules

- Never delete `.omo/`, `.flow/`, or any `.txt` files at the project root (e.g. `errorandFeatureRequest.txt`, `futureroadmap.txt`)
- Never delete `README.md`
- Android-only project — do not add or generate files for other platforms (iOS, web, macOS, Windows, Linux) unless explicitly requested
- Never push changes to git by default. Always compile and test on the emulator/device first, and only push when explicitly instructed by the user.
