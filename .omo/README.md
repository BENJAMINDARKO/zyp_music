# YTMusix — OMO Agent Workspace

This project was generated by FlowOS and is configured for Oh My OpenAgent.

## Quick Start

```bash
# Install OMO if you haven't already
bunx oh-my-openagent install

# Load this project's skill
bunx oh-my-openagent skill load .omo/skill.md

# Start working
bunx oh-my-openagent start
```
